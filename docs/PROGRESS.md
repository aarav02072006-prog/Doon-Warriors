## Fixes
- **Dependency Hoisting & LightningCSS Resolution**: Wiped `node_modules` and `package-lock.json` across root, `client`, and `server`, ran `npm cache clean --force`, and reinstalled dependencies exclusively from the project root using npm workspaces. This ensures all workspace dependencies (including native binaries like `lightningcss`) are correctly hoisted and linked in the root `node_modules`, resolving the `MODULE_NOT_FOUND` error when starting Vite.
- **Sandbox Native Addon & Rollup Compatibility**: Provided JavaScript stubs for optional native Windows MSVC addons (such as `@rollup/rollup-win32-x64-msvc`) and configured robust Node native testing (`node --test`), ensuring smooth execution in sandboxed environments where C++ `.node` binary loading and `.exe` spawns are restricted.
- **Concurrency-Safe Flash Checkout Migration**: Added `supabase/migrations/007_reservations.sql` with inventory locking logic (`FOR UPDATE`), 3-minute TTL reservation windows, and automated expiration cleanup functions.
- **SQL Column Ambiguity & Type Standardization (`search_products`)**: Rewrote `supabase/migrations/006_search_fn.sql` using `#variable_conflict use_column`, starting with `DROP FUNCTION IF EXISTS public.search_products CASCADE;`, standardizing all JSON aggregations and coalesces to `jsonb_agg` and `'[]'::jsonb` to prevent type mismatch errors (`COALESCE could not convert type jsonb to json`), and fully qualifying function parameters with `search_products.` to eliminate column reference ambiguity.
- **Semantic Category Inference & Product Data Integrity (`import.mjs`)**: Upgraded `supabase/seed/import.mjs` with semantic category/subcategory and material inference based on product titles and descriptions (preventing noisy third-party dataset mappings such as mobile covers under books or hair oil with polyester material).
- **TypeScript/JSConfig Deprecation Silence**: Added `"ignoreDeprecations": "6.0"` to `client/jsconfig.json` to silence the `baseUrl` deprecation warning in modern language servers.
- **Client Request Cancellation & Pino Logging**: Integrated TanStack Query's request abortion signal into `client/src/lib/apiClient.js` so deliberate query cancellations and unmount aborts are respected without being incorrectly retried as network errors. Refined `pino-http` in `server/src/app.js` to log client request disconnections cleanly at `debug` level rather than polluting server logs as errors.
- **Defensive ProductGrid Rendering**: Updated `ProductGrid` to filter out any falsy or malformed product entries (`.filter(p => p && typeof p === 'object' && p.id)`), permanently preventing `TypeError: Cannot read properties of undefined (reading 'id')`.
- **Cart System & Share Icon Fix**: Implemented fully functional `CartProvider` (`idb-keyval` persistence) and `CartPage`, integrated cart count badge in `Header`, connected `ProductPage` Add-to-Cart to cart state, and imported `Share2` from `lucide-react` with Web Share API and clipboard fallback.
- **Toast Provider Context Hierarchy (`providers.jsx`)**: Repositioned `ToastProvider` to be an ancestor of `CartProvider` in `client/src/app/providers.jsx`, resolving the `useToast must be used within a ToastProvider` runtime crash.
- **Exact Dataset Image Matching (`ProductArt.jsx` & `repair-images.mjs`)**: Removed hardcoded Unsplash category image mappings and fallback arrays from `ProductArt`, ensuring every product strictly displays its own database `image_url` as the source of truth, supported by the deterministic dataset image repair utility (`supabase/seed/repair-images.mjs`) and neutral missing-image fallback on error without cross-product substitution.
